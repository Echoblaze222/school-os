Logo system — motion

The mark, in motion

Each of the four tiles zooms out and back in, one after another, looping continuously — a simple round-robin pulse rather than all four moving together. Reads as a loading state, an "always on" system, or a splash-screen moment.

Loop length: 2 seconds total, 0.5s per tile — each tile's own "zoom out, zoom in" takes 0.5s (0.25s growing, 0.25s shrinking), then it holds still for 1.5s while the other three take their turn.
Implementation

Drop-in CSS

Same structure as the static mark — just add these classes to the four tiles and this stylesheet. No JavaScript required.

/* apply .tile to all four <rect> elements, plus .t1 .t2 .t3 .t4 in order */
@keyframes tilePulse {
  0%   { transform: scale(1); }
  12.5%{ transform: scale(1.28); }
  25%  { transform: scale(1); }
  100% { transform: scale(1); }
}
.tile {
  transform-box: fill-box;
  transform-origin: center;
  animation: tilePulse 2s ease-in-out infinite;
}
.t1 { animation-delay: 0s;   }
.t2 { animation-delay: 0.5s; }
.t3 { animation-delay: 1s;   }
.t4 { animation-delay: 1.5s; }
